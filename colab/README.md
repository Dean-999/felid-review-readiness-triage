# Colab

There are no separate active Colab implementations. Cloud execution uses the
same canonical code as local/Kaggle execution so that a platform change cannot
silently create a new algorithm version.

Current PF-ERI v2 full-frame instructions and code are in
`gpu/kaggle_v2_local_matcher_v2/README.md`. Historical Phase 7–19 Colab sources
are preserved under `archive/pferi_v1/reproducibility/` and their experiment
outputs remain under `archive/pferi_v1/outputs/`.
