# Sampling-Strata Design Outline

Status: planning scaffold for the prose proposal; not a protocol and not a sampling authorization.

- Define the target unit as one eligible canonical unordered pair from the frozen top-20 dual-descriptor queue; duplicate memberships remain metadata and never become additional review rows.
- Exclude every prior measurement pilot, interface dry run, operational rehearsal, retired rehearsal pair, unavailable image, and cross-image-role pair before sampling.
- Run retained outcome-free automatic image measurements on all 3,000 images before image allocation; do not use reviewer outcomes, identity truth, model predictions, routes, or oracle annotations.
- Allocate exactly 1,000 images to each of development, calibration, and confirmation using blocked randomization over graph-degree quintile and automatic image-quality state.
- Derive pair retrieval strata from descriptor support category and minimum observed candidate-rank band, using three descriptor categories and three rank bands.
- Run the frozen automatic pair-evidence pipeline on every eligible within-role pair before pair sampling; automatic failure remains a sampling state rather than an exclusion.
- Draw the representative deployment-confirmation sample before the mechanism-confirmation sample so that mechanism enrichment cannot distort the deployment frame.
- Use proportional stratified sampling for calibration and deployment, recording exact first-order inclusion probabilities and applying the accepted Hájek estimator when probabilities differ.
- Use outcome-free balanced sampling for development across retrieval and automatic-evidence states, because development needs feature-range coverage rather than a prevalence estimate.
- Use outcome-free challenge strata for mechanism confirmation, separating measurement failure, image-quality stress, low local correspondence, descriptor exclusivity, dual-descriptor discordance, and ordinary reference cases.
- Use fixed water-filling allocation for equal-coverage samples and Hamilton largest-remainder allocation for proportional samples; never alter quotas after outcomes.
- Report frame counts, selected counts, inclusion probabilities, image-degree distribution, pair-degree distribution, exclusions, sparse cells, and any deterministic pooling before packet construction.
- Keep camera, site, illumination, and identity out of the primary strata because the current freeze manifest does not provide them; permit only a versioned pre-seed amendment or restricted sensitivity analysis.
- Stop before official seed generation unless full-image quality measurements, the hashed historical-pair exclusion register, and image-strata preflight pass. After the one-time image allocation, stop before pair sampling unless within-role automatic pair measurements, cell capacity, exact role separation, zero-crossing, and probability accounting all pass.
