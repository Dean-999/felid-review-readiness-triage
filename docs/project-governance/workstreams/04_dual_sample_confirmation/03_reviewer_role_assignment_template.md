The identity-separation check passes only if every pair is assigned to two different first-pass reviewers. The adjudication check passes only if each possible disagreement has an eligible third person who did not first-pass that pair. The access-control check passes only if reviewers and adjudicators cannot access model outputs, descriptor scores, quality scores, candidate rank, hidden strata, analytical role, confirmation role, or another reviewer's answer before the permitted adjudication stage.

The project owner should record a final disposition of `PASS`, `FAIL_IDENTITY_SEPARATION`, `FAIL_ADJUDICATION_CONFLICT`, or `FAIL_ACCESS_CONTROL`, together with the decision date and a concise rationale.
