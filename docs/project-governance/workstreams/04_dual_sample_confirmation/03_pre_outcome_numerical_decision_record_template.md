# Pre-Outcome Numerical Decision Record Template

Status: blank template; completing it requires project-owner acceptance before any v2 outcome review.  
Applies to: Workstream 04 Task 03.

This record is intentionally not prefilled. The project owner must state the scientific and operational choices in full before the binding simulation runs. Historical v1 outcomes, any v2 outcome information, and an attractive row from the nonbinding sensitivity analysis are prohibited rationales for completing a field. The final record must also state the source hash of the completed binding simulation and the timestamp at which the owner accepts it.
