# Workstream 06: Species Adapter and Conservation Extension

Status: future extension; it does not contribute to the PF-ERI v2 CzechLynx primary claim.  
Primary dependency: Workstream 05 must end in a bounded, auditable result.  
Exit dependency: none; every new species begins its own local validation cycle.

## Purpose

This workstream turns a confirmed CzechLynx evidence-admission interface into a responsible conservation extension. Its goal is not to claim that one PF-ERI score transfers across felids. Its goal is to retain a stable core—the canonical pair contract, route actions, loss accounting, audit manifest, calibration discipline, and explanation record—while creating a locally validated species adapter for body layout, patterned evidence, camera modality, and reviewer workflow.

## Procedure

The first candidate is Mainland Clouded Leopard because a compatible, licensed, and auditable known-identity or pair-label data source would most directly test whether the CzechLynx measurement and routing logic can be adapted to a conservation-relevant patterned felid. Marbled Cat is a valuable second extension because it tests a rarer and potentially more difficult setting, but it may not be selected merely because it makes a compelling story. Each candidate must first pass data-governance review: lawful access, image-display permissions, a frozen manifest, source provenance, adequate pair construction, independent blind reviewers, and explicit local stakeholder or expert arrangements.

For a selected species, reproduce Workstreams 01 through 05 locally. Define the animal detector and crop policy, body regions, laterality and pose categories, visible patterned regions, night or infrared handling, automatic feature failures, candidate queue, reviewer semantics, calibration set, and loss parameters. Begin by evaluating reviewability and adapter measurement. Identity-related utility may be evaluated only when verified individual identities or an independently audited same/different reference set exist. The report must state camera configuration, side distribution, illumination distribution, missingness, expert minutes, and all changes from the CzechLynx adapter.

The reusable tool must expose the reason for each route, the available and missing features, adapter version, model version, calibration version, and audit-manifest identifier. A direct score transfer that fails is informative; it may not be hidden by post-hoc recalibration. Any redesigned adapter or threshold requires a new local confirmation set.

## Required Artifacts and Exit Decision

The workstream requires a data-rights and provenance record, local canonical-pair and feature contracts, adapter specification, blinded-review protocol, calibration and confirmation manifests, and a species-specific claim audit. The exit decision is a bounded local result, a documented transfer failure, or a decision not to proceed because the data contract is inadequate. No external species result upgrades the CzechLynx claim retroactively, and no CzechLynx result licenses an uncalibrated external-species claim.
