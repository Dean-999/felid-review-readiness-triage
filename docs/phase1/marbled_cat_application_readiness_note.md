# Marbled Cat Application Readiness Note

## Purpose

This document explains how the review-readiness triage protocol could apply to future Asian felid conservation work, especially Marbled Cat monitoring.

Marbled Cat is not part of the current validation study.

## Why Marbled Cat Is Relevant

Marbled Cat is an Asian forest felid with conservation relevance.

It is difficult to study because it is elusive, forest-associated, and not commonly observed. Camera traps are important for detecting rare or cryptic felids, but detections alone do not automatically provide individual-level identity evidence.

This makes Marbled Cat a useful future application scenario for a review-readiness protocol.

## How the Current Project Could Help Future Marbled Cat Work

The current project can contribute a transferable workflow logic:

1. separate species-level detection from individual-level readiness;
2. triage images before Re-ID review;
3. record visible side, diagnostic region, pattern visibility, blur, occlusion, and lighting;
4. avoid treating candidate evidence as true identity;
5. calibrate thresholds within the target species and dataset;
6. quantify safety versus evidence loss before conservation claims.

The transferable part is the review-readiness protocol.

The non-transferable part is the numerical threshold or performance result from CzechLynx.

## Required Future Data Conditions

Before Marbled Cat Re-ID validation is possible, a future project would need:

- authorized Marbled Cat camera-trap images;
- clear data-use permission;
- repeated detections;
- timestamp metadata;
- camera/site metadata;
- side or viewpoint labels;
- image quality fields;
- expert-reviewed candidate identities or verified individual IDs;
- enough repeated individuals to construct same-individual pairs;
- enough different individuals to construct different-individual pairs;
- species-specific calibration;
- expert review involvement;
- conservation-sensitive location handling.

## Application Scenario

A future Marbled Cat monitoring project could use the review-readiness protocol as follows:

1. collect authorized camera-trap images;
2. filter images to Marbled Cat detections;
3. label each image as review-ready, review-limited, or unidentifiable;
4. record visible side, pattern visibility, blur, occlusion, lighting, and metadata completeness;
5. send only review-ready and selected review-limited images to expert Re-ID review;
6. use verified or expert-reviewed IDs to calibrate Re-ID similarity thresholds;
7. report risk–coverage trade-off before making any conservation inference.
