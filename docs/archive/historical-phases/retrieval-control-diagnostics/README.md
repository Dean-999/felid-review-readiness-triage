# Phase 8 Retrieval-Control Diagnostics

Phase 8 tested fixed-descriptor retrieval control and early PF-ERI selection policies.

Current role: historical evidence and cautionary baseline.

## What It Contributed

- Fixed descriptor retrieval benchmarks.
- Risk-coverage and policy-frontier framing.
- Evidence that PF-ERI should be evaluated as risk control, not just top-1 gain.
- Downstream contamination sensitivity as application-value analysis.

## Boundary

- Use Phase 8 to justify later review-routing and pair-level admissibility work.
