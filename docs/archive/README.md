# Archive Map

Date: 2026-06-23

This folder preserves superseded plans and specs. These files are not deleted
because they explain prior design decisions, but they should not be used as the
current roadmap.

## Folders

- `superseded_plans/`: older executable plans replaced by the current Phase 16
  strategy.
- `superseded_specs/`: earlier design specs whose useful decisions were merged
  into Phase 14, Phase 15, or Phase 16.

## Rule

Use archived files only for historical rationale. If an archived file conflicts
with `PROJECT_RULES.md`, `docs/CURRENT_PROJECT_MAP.md`, or the Phase 16 plan,
the current files win.
