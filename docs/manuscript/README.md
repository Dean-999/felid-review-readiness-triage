# Historical V1 Manuscript-Facing Archive

The documents in this directory preserve v1 manuscript-facing analyses, figures, captions, reviews, and submission-preparation material. They are historical records and must be read under the `v1_exploratory_not_confirmatory` status in `PROJECT_RULES.md`. They cannot be submitted, cited as final evidence, used to define a v2 threshold, or presented as a completed PF-ERI validation.

The current v2 protocol is defined by `PROJECT_RULES.md`, `docs/CURRENT_PROJECT_MAP.md`, and `paper/protocols/`. A future manuscript must be regenerated from v2 raw logs, manifests, feature measurements, and locked confirmatory analyses rather than patched around these historical documents.
