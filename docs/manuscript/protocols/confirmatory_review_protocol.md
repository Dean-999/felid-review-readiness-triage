# Historical Phase18N Review Protocol (PF-ERI v1)

Date locked: 2026-07-10

Status: `v1_exploratory_not_confirmatory`. This document reproduces the
historical packet procedure; it is not the active PF-ERI v2 confirmatory
protocol. The active protocol is `paper/protocols/confirmatory_review_protocol.md`.

## Objective

Phase18N tests the confirmatory claim that PF-ERI functions as a post-retrieval, pair-level evidence admission layer for wildlife Re-ID candidate review. The validation unit is a descriptor-retrieved CzechLynx candidate pair. The primary endpoint is human reviewability / evidential admissibility, not identity accuracy.

## Sampling Contract

Rows were sampled from strong-descriptor PF-ERI pair-feature tables restricted to evaluation rows. The sampling strata were:

```text
descriptor name
candidate rank bin
descriptor similarity tertile
weakest-image quality stratum
same-ID vs different-ID known CzechLynx audit status
PF-ERI admissibility tertile
```

Image availability was enforced. The original Phase18A manifest refers to older freeze paths, so the builder resolved unavailable image paths by matching filenames against `data/frozen/pferi_v2/`. The audit records the number of fallback image references. The review packet writes paths that are available on the local filesystem.

## Reviewer Assignment

Each pair should receive three independent blinded reviews. The generated files are:

```text
reviewer_1_blind_review_form.csv
reviewer_2_blind_review_form.csv
reviewer_3_blind_review_form.csv
```

Reviewers should not communicate about labels during first-pass review.

## Endpoint Definition

A pair is `review_ready` when the two images contain enough comparable visual evidence for responsible individual-level review. A different-ID pair can be review-ready if the images allow a confident rejection.

A pair is `not_review_ready` when the pair should not enter immediate evidence use because comparable pair evidence is inadequate.

A pair is `uncertain` when the reviewer cannot determine whether the pair is review-ready after considering the reason fields.

## Known Limitation Locked Before Review

The available quality proxy has limited variation in the current strong PF-ERI tables. In the generated Phase18N audit, the weakest-image quality cutoffs can collapse at 0.55. The analysis will still include the pre-specified quality control and quality-stratum audit, but the manuscript must report weak quality-stratum variation if it remains present. The study must not claim that this packet proves independence from all possible image-quality measures.

## Claim Boundary

Phase18N can support PF-ERI as an evidence-admission layer if reviewability alignment, quality/similarity sensitivity, reviewer reliability, and review-routing utility hold under the locked analysis plan.

Phase18N cannot claim:

```text
PF-ERI is a descriptor
PF-ERI assigns animal identity
PF-ERI improves mAP, MRR, or top-k identity retrieval
PF-ERI validates Bobcat identity accuracy
PF-ERI provides a universal cross-domain guarantee
```
