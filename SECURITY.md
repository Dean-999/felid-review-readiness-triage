# Security and Data Handling

This is a private research repository. Do not place credentials, raw wildlife photographs, reviewer responses, restricted identity mappings, or participant-linked material in Git history.

Report an accidental disclosure or suspected credential exposure directly to the repository owner. Revoke exposed credentials immediately and preserve the affected file paths and commit identifiers for remediation.

Repository access does not replace the project data-handling rules. The binding scientific and restricted-data boundaries remain in `PROJECT_RULES.md` and the applicable task contracts.
